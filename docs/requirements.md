# 私人工作站：功能需求与完成情况

本文记录当前已实现的功能范围，作为首次提交的验收基线。当前完成第 1 至第 4 阶段，第 5 阶段尚未开始。

## 项目目标与技术方案

为个人研发工作提供长期使用的 Markdown 日报工作台，同时作为后续智能体测试项目的业务基础。

- 后端：Python 3.13、FastAPI、SQLAlchemy、Alembic，使用 uv 管理依赖。
- 前端：TypeScript、Vue 3、Vite、Pinia，使用 npm 管理依赖。
- 数据库：SQLite，通过配置统一确定文件位置。
- 开发约束：面向初学者维护，业务模块提供中文说明，保持接口、存储和页面职责清楚。

## 第二阶段：数据库与迁移（已完成）

- [x] 使用 document 表保存标题、Markdown 正文、报告周期、版本及扩展信息。
- [x] 使用 document_revision 表保存版本快照及变更来源。
- [x] 预留日报、周报、月报的数据类型，提供完整周期约束。
- [x] 通过唯一索引限制同一周期只能有一篇未删除的同类报告。
- [x] 通过 Alembic 显式管理建表和后续结构升级。
- [x] 启用 SQLite 外键、WAL、写入等待超时及明确事务模式。
- [x] 报告日期按北京时间确定，操作时间保存为 UTC。

## 第三阶段：日报核心接口（已完成）

- [x] 打开或创建今日日报及指定日期日报，重复打开不会覆盖已有内容。
- [x] 创建时生成 Markdown 模板及初始版本快照。
- [x] 提供按报告日期倒序的分页列表及文档详情接口。
- [x] 列表接口支持报告类型和日期范围参数。
- [x] 保存时通过 expected_version 检查预期版本，过期版本返回 HTTP 409。
- [x] 文档更新与快照写入在同一个事务中提交或回滚。
- [x] 校验标题长度，允许空正文，拒绝未约定字段和无效输入。
- [x] 数据库繁忙和其他存储异常返回明确的接口错误，不暴露正文或内部堆栈。
- [x] 通过独立数据库验证并发创建、并发保存、持久化及失败回滚。

- [x] 提供浅色三栏布局：导航、日报列表、编辑工作区。
- [x] 支持今日日报入口、历史日期补写、列表分页和刷新。

- [x] 提供保存、切换、冲突和 Markdown 清理的前端回归测试。

## 当前验收方式

启动、迁移、检查命令及代码阅读顺序见项目根目录 README.md。

通过页面创建日报，编辑并保存后刷新重读；补写历史日期并分页切换；验证未保存提示、网络失败保留输入、后端重启后的持久化及双窗口版本冲突。浏览器联调数据应放在独立验收库中。

## 版本控制范围

代码、锁文件、迁移脚本、自动测试、共享运行配置、开发规范及需求文档纳入 Git。真实数据库、运行数据、虚拟环境、node_modules、构建产物、缓存、日志、.env 和本机 IDE 状态不纳入 Git。
